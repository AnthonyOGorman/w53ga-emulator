⚠ Without it no map data loads. How do I get it?

The unit's map database is bound to the card it was written to. Without that card's CID the unit reports an SD card error at start-up and the map stays empty.

The CID is built into the card, not a file, and USB card readers hide it. Read it where the card sits in a built-in slot:

  • Linux (laptop SD slot, Raspberry Pi): cat /sys/block/mmcblk0/device/cid
  • Android with a microSD slot (often needs root): cat /sys/class/mmc_host/mmc*/mmc*:*/cid

Paste the 32 hex digits here. Keep it private: it identifies your card. README: Card CID
